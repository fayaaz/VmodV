VmodV is a modular VJing app for Linux: Scenes, Performance, and a gallery of shader, 2D and Point10 modules driven by audio, MIDI and OSC. This page is the live catalogue of everything bundled in the app.

What you'll find here

The full gallery

Every registered module — 16 2D tools, 27 Point10 scenes, 36 built-in effects and the 402-shader ISF corpus — with author, category, inputs and defaults.

Live previews

Open any shader to see it animate in the browser. The preview clock and audio simulation run in WebAssembly; WebGPU draws the module's real WGSL source.

Always in sync

The catalogue is generated from the same Rust module registry the application uses, so names, props and shaders never drift from what ships in the installer.
