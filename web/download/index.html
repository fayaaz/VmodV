Linux

Full feature set — the primary target.

One file, no install. Needs FUSE (libfuse2) or run with --appimage-extract-and-run.

Pick the package built for your Ubuntu base; it declares its runtime dependencies.

▣

Windows

Best-effort portable ZIP — no installer.

Unzip and run VmodV.cmd. GStreamer ships inside the ZIP. Camera, screen and system-audio capture are Linux-only.

◈

macOS

Best-effort portable app bundle — no installer.

Install GStreamer (brew install gstreamer gst-plugins-base) and run VmodV.command. If Gatekeeper blocks it, clear the quarantine attribute.

What you need

A Vulkan driver (a modern GPU driver, or mesa-vulkan-drivers for the lavapipe software fallback), PipeWire or PulseAudio for audio capture, ALSA and GStreamer. Wayland is preferred; X11 works too.

VmodV's own code is MIT; bundled modules and assets carry their own licences — see third-party notices. Links always resolve against the latest published GitHub release, so this page does not need updating for a new version.
