Linux

One file, no install.

What you need

  • libfuse2, or run with --appimage-extract-and-run.
  • A Vulkan driver — a modern GPU driver, or mesa-vulkan-drivers for the lavapipe software fallback.
  • PipeWire or PulseAudio for audio capture, and ALSA.
  • GStreamer base/good/bad plugin sets for video capture; the image bundles its own plugins, but host codecs vary.

Pick the package built for your Ubuntu base.

What you need

  • Ubuntu, or a compatible Debian-based distro, with apt.
  • sudo apt install ./VmodV-*-amd64*.deb — apt installs the runtime dependencies (PipeWire, ALSA, GStreamer, Vulkan loader, XKB) for you.
  • A Vulkan driver; mesa-vulkan-drivers is recommended for the lavapipe fallback if your GPU has no driver.
  • Wayland is preferred; X11/XWayland works too.
▣

Windows

Unzip and run VmodV.cmd.

What you need

  • Nothing extra for video — GStreamer ships inside the ZIP.
  • A working graphics driver; wgpu picks the best available backend.
  • Camera, screen and system-audio capture are Linux-only; rendering, audio input and MIDI work.
◈

macOS

Unzip and run VmodV.command.

What you need

  • GStreamer from Homebrew: brew install gstreamer gst-plugins-base.
  • A working graphics driver; wgpu picks Metal or Vulkan as available.
  • If Gatekeeper blocks the ad-hoc signed bundle: xattr -dr com.apple.quarantine VmodV.app VmodV.command.
  • Camera, screen and system-audio capture are Linux-only.
